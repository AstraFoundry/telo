# Telo client audit — feature gaps, architecture compliance, UI polish

Date: 2026-09-09. Scope: read-only audit of the whole repository. Benchmarks: Telegram Desktop (tdesktop), Telegram X, Nekogram.

**Method.** Telo's current state is grounded in repository evidence: `docs/telegram/tdlib-capability-matrix.json` (TDLib 1.8.67), `docs/telegram/baseline.md`, `docs/project/architecture.md`, and grep verification of `backend/src` / `frontend/src` (message content-type mappers, composer, IPC channels). Benchmark-client columns reflect the reference clients' well-known feature sets; they are used for gap direction, not per-cell re-verification. Three parallel code audits covered FSD (`frontend/src`), DDD (`backend/src`), and UI polish/animation opportunities (`frontend/src`); their findings are reproduced with `file:line` evidence.

Legend: ✅ covered · 🟡 partial · ❌ missing · ➖ out of product scope (per the capability matrix's `not-applicable`).

### 1.8 Gap summary (recommended order)

- **P0 (1):** voice/video-note **recording** — the only daily-driver gap; playback already works end-to-end.
- **P1 (5):** server chat-folder editing, pin/unpin message action, scheduled messages, polls/quizzes, (folder editing pairs naturally with the existing keyword-folder UI in Settings → Folders).
- **P2 (everything else):** QR login, sessions, app lock, proxy, tray/badge, jump-to-date, comments, export, dice, location/contact/game content, GIF send panel, media pre-send editing, admin tools, invite links, forum topics, inline bots, block/report, auto-delete, privacy UI, native translate, message-details view.
- **Explicitly out of scope (unchanged):** VoIP, story browsing, Mini Apps/Stars/wallets; >3 accounts is deliberate tdesktop parity.
